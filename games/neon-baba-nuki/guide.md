# 【遊び方・攻略】ダイスが呼ぶ大波乱！『ネオン・ババ抜き』のルールと心理戦の極意（OBS透過対応）

「ババ抜き」といえば、誰もが知るトランプゲームの古典ですが、**『ネオン・ババ抜き (Neon Baba-Nuki)』** はそこに**「シャッフルダイス」**という強烈な駆け引きギミックを融合させた、1手1手から汗がにじむ超高速の心理戦カードバトルです。

1試合はわずか1〜2分。ポータルの合言葉である「10秒で始まるオンライン対戦」そのままに、URLを共有するだけでブラウザ上で即座に4人卓の熱狂が始まります。

---

## 1. 基本ルールとゲームの流れ

『ネオン・ババ抜き』は、手札から同じ数字のペアを捨てていき、最後までジョーカーを持たずに手札をなくす（あがる）ことを目指すゲームです。

### ① スピーディーなカード構成
- **使用カード**: 数字 `1〜7` の4スート（計28枚）＋ `JOKER`（1枚）＝ **合計29枚**
- カードが配られた瞬間に**手札のペアは自動で破棄**されるため、試合開始時の手札は各自わずか2〜4枚程度。最初からクライマックスの状態で勝負が始まります。

### ② ターンの進行と手札整理タイム
1. 試合開始時、席順と最初の手番（親）がランダムにシャッフルされて決まります。
2. 自分の手番になると、前のプレイヤーの手札が選択可能になります（制限時間は1手15秒）。
3. 相手の手札から好きなカードを1枚クリックして引きます。ペアが揃えば自動で捨てられます。
4. カードが引かれた後、**5秒間の「手札整理タイム」**が始まります（画面中央の紫ゲージがカウントダウン）。引いた側は手札を並び替えたり突き出しブラフを仕掛けることができ、次の手番の人は相手の手札が整うまで待機します。
5. 手札がなくなればその時点で「勝ち抜け（あがり）」となります（※残り1枚同士で引いてペアが揃った場合、トランプの通例に準拠して「引かれて手札が0枚になった側」が上位判定となります）。

### ③ プレイ人数とCPU補完
- 最大4人対戦（可変人数対応）。
- 1人ソロプレイや2〜3人のオンライン対戦でも、足りない席には自動で賢い「BOT（CPU）」が着席するため、常にバランスの取れた4人卓でプレイできます。

## 2. 目玉ギミック「シャッフルダイス」のルール

本作最大の醍醐味は、画面右下にある**「🎲 SHUFFLE」ボタン**です。

### 🎲 発動条件：ジョーカーを持っている人の手番時のみ！
シャッフルボタンを押せるのは、**「現在手札にJOKERを持っているプレイヤー」が「自分の手番（カードを引く前）」を迎えたときだけ**です（1試合に1人1回限定）。

自分の手番が回ってきた際、相手からカードを引くか、それともサイコロに賭けて手札を回すかの決断を迫られます。ダイス発動時は**誰が振ったかは伏せられたまま「シャッフルチャンス！」の演出が開始される**ため、出目によってババが今どこからどこへ動いたのか、全員が疑心暗鬼になる極上の心理戦が巻き起こります。

※プレイヤーがあがり、残り2人（一騎打ち）になった後はシャッフルボタンは使用不可となります。

### 🎲 人数によって変化するサイコロの目と確率

卓の人数（生き残り人数）に応じて、ダイスの確率バランスが緻密に調整されています。

#### 【4人卓のとき】
| 出目 | 効果 | 出現確率 |
| :--- | :--- | :---: |
| 🔄 **右1** | 生存者全員の手札が【時計回り】に1人分スライド | **33.3%** |
| 🔃 **左1** | 生存者全員の手札が【反時計回り】に1人分スライド | **33.3%** |
| 🔀 **対面** | 向かい側のプレイヤーと手札を【全交換】 | **16.7%** |
| 💀 **ドクロ** | **シャッフル失敗！** 移動なし（ババが自分の手元に残る） | **16.7%** |

ババが他人に移る確率は **約83.3%**。ババが動かなかった「ドクロの悲劇（16.7%）」を引いたときは、思わず声が出てしまう盛り上がりポイントです。

#### 【3人卓のとき（1人抜け後）】
1人抜けて3人になると「対面」がなくなるため、ドクロが出やすくなりすぎない「概念上の5面ダイス」へ自動切り替えされます：
- 🔄 **右1**: **40.0%**
- 🔃 **左1**: **40.0%**
- 💀 **ドクロ**: **20.0%**

ババが誰かに移る成功率は **80.0%** を維持し、3人卓でもストレスなく勝負に挑めます。

## 3. 勝率を上げる心理戦・攻略のコツ

### ① カード突き出しブラフ（相手画面にもリアルタイム反映！）
手札直上にある操作バーから「⬆️ タップで突き出し」を選びカードをタップすると、**1枚だけ上にスッと飛び出させる**ことができます。
そしてこの突き出しは、**相手がカードを引くときの画面にもリアルタイムでそのまま反映**されます。

- 「飛び出ているカードはババなのか？ 引かせようとする罠なのか？」
- 「あえて引っ込めて、普通のカードのように紛れ込ませるか？」

テレビ番組さながらの「カードを前に出して相手を誘う」心理的ブラフを直感的に仕掛けることができます（相手にカードを引かれるとスッと元の位置に戻ります）。もう一度「⬆️ 下ろす」を押すか同じカードをタップすれば引っ込めることも可能です。

### ② 5秒間の手札整理タイムでの「並び替え」活用法
カードを引いた直後の「手札整理タイム（5秒間）」中に、手札直上の**「🔀 並び替え」ボタン**を押すのが極めて有効です。
万が一ジョーカーを引いてしまった場合でも、即座に並び替えることで「どの位置に引いたカードが入ったか」を次の相手に悟らせず、完全にカモフラージュできます。5秒間の猶予があるため、並び替えてからじっくり突き出しブラフを仕掛けることも可能です。

### ③ シャッフルダイスを振るタイミング
シャッフルは自分の手番（引く前）にしか使えません。
- **おすすめのタイミング**: 誰かが残り1枚になって次に上がられてしまいそうな手番や、1人抜けて3人卓になった直後など、**「ここでババを手放せば一気に勝利に近づく」**という勝負どころで使うのが極めて効果的です。

## 4. Discord通話や配信での活用法

『ネオン・ババ抜き』は、Discordの画面共有や配信者向けの機能も充実しています。

- **OBS背景透過対応**:
  - ゲームURLに `?obs=true&transparent=true` を付けることで、背景が完全に透過（アルファチャンネル）されます。
  - サイバー調のカードやダイスだけが配信画面の隅に美しく浮かび上がるため、配信画面のレイアウトを邪魔しません。
- **配信・収益化全面OK**:
  - ひつまぶしの全ゲームは、YouTubeやTwitch等でのライブ配信・動画投稿・収益化を歓迎しています（事前連絡不要）。
- **配信者モード対応**:
  - 部屋コードを `****` に伏字化できるため、意図しない映り込みやゴースティングを防げます。
