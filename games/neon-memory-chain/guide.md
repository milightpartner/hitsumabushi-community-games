# ネオン・メモリーチェーンの遊び方・ルール｜前の人の列を覚えて1つ足す記憶ゲーム

## ネオン・メモリーチェーンとは

前の人が入力した矢印の列を順番どおりになぞり、最後に自分で1つ足して次の人へ回す記憶ゲームです。列は1人ごとに1つずつ伸びていくので、自分の番が来るまでの間も、ほかの人の入力を見て覚え続けることになります。

間違えた人はその場で脱落しますが、ゲームは止まらずに次の人へ進みます。2〜4人で遊べて、1試合は数分で終わります。

## 遊び方

### 始まり方

試合が始まると、最初の1つの矢印が光ります。最初の人はそれを入力してから、好きな矢印を1つ足します。

### 自分の番

1. 今の列を、最初から順番どおりに入力します。
2. 最後に好きな矢印を1つ足します。これで列が1つ伸び、次の人の番になります。

入力した矢印は、画面中央の列の枠に順番に表示されていきます。列の長さは「チェーン」として常に表示され、今入力する枠は光って示されます。まだ入力していない枠の中身は伏せられています。

### 時間

1つ押すごとに2秒の制限時間があります。押すたびに2秒から測り直します。素早く押しても次の入力の持ち時間は増えず、2秒以内に押せなければ時間切れです。制限時間は試合の最後まで変わりません。

### 脱落と順位

- 入力を間違えるか、時間切れになるとその場で脱落します。
- 脱落した人の番では列が伸びません。次の人は同じ列に挑みます。
- 残りが1人になったら、その人の勝ちです。脱落が早い人ほど下の順位になります。

手番の順番と、今の番の人・次の番の人は画面の端に表示されています。連戦では、最初に入力する人が1人ずつずれていきます。

### 操作

| 入力 | ボタン | キーボード |
|---|---|---|
| 上 | ▲ | ↑ / W |
| 右 | ▶ | → / D |
| 下 | ▼ | ↓ / S |
| 左 | ◀ | ← / A |

方向ごとに色と音が決まっているので、形だけでなく色と音でも覚えられます。

## 上達のコツ

- **ほかの人の番こそ集中します。** 自分の番で思い出すより、前の人の入力を見ながら頭の中で一緒になぞっておく方が確実です。
- **音で覚えます。** 方向ごとに音の高さが違うので、列をメロディとして覚えると長い列でも崩れにくくなります。
- **足す1つで相手を揺さぶります。** 直前と同じ方向を続けたり、急に向きを変えたりすると、次の人が覚えにくくなります。
- **急ぎすぎません。** 1つごとに2秒あれば間に合います。焦って押し間違えるより、一定のリズムで正確に入力する方が長く残れます。

## 配信で遊ぶとき

ポータルの OBS モードでは背景が透明になり、配信画面にゲームだけを重ねられます。
