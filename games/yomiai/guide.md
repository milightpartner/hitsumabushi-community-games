# 【遊び方】ヨミアイ：相手の数字を読み合う、同時出しの心理戦カードゲーム

「**ヨミアイ**」は、全員が同時に数字カードを1枚ずつ出し合い、場の得点カードを奪い合う2〜6人用のカードゲームです。大きい数字を出せば勝てるとは限らず、**他の人とかぶると無効** になるのがポイント。相手の手を読み合う心理戦が楽しめます。人数が足りないときはCPUが入ります。

## 1. 準備

- 全員が **1〜15の数字カードを1組（15枚）** ずつ持っています。
- 得点カードは **-5〜-1 と 1〜10 の15枚**（0はありません）。よく混ぜて山にします。

## 2. ラウンドの流れ

1. 得点カードを1枚めくって場に出します。
2. 全員が、手札から数字カードを **1枚、裏向きで** 選びます。
3. 全員が選び終えたら **一斉に公開** します。
4. 出したカードは、結果に関係なく捨て札になります。

これを、手札がなくなるまで **15ラウンド** くり返します。

## 3. 得点カードのゆくえ

- **同じ数字を出した人同士は、その数字ごと無効** になります。3人以上が同じ数字でも、全員無効です。
- 残った（誰ともかぶっていない）数字の中で、
  - 得点カードが **プラス** なら、**一番大きい数字** を出した人が獲得します。
  - 得点カードが **マイナス** なら、**一番小さい数字** を出した人が引き取ります。
- 全員が無効になって誰も獲得できなかったときは、得点カードは場に残り、**次のラウンドの得点カードと合わせて** まとめて争われます。最終ラウンドで誰も獲得できなかった場合、その得点カードは誰のものにもなりません。

## 4. 勝敗

15ラウンドが終わったら、獲得した得点カードの **合計が一番高い人の勝ち** です。

## 5. 攻略のコツ

- **大きい数字ほどかぶりやすい**：高い得点カードには、みんなが15や14を出したくなります。あえて少し下の数字を出すと、上がかぶって自分だけが残ることもあります。
- **マイナスは小さい数字で引き取ってしまう**：マイナスの得点カードでは、一番小さい数字を出した人が引き取ります。安全に逃げたいなら、他の人が出しそうな小さい数字にあえて合わせて、無効を狙うのも手です。
- **手札の残りを見る**：使ったカードは戻ってきません。誰がどの数字を使い切ったかを覚えておくと、終盤の読み合いで有利になります。
- **持ち越しは大きな勝負**：得点カードが持ち越されると、次のラウンドは合計点が大きくなります。強いカードを使うならここです。
