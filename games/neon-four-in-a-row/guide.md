# 【遊び方】ネオン四目並べ：石を落として4つ並べる2人対戦

「**ネオン四目並べ**」は、縦に立てた7列×6段の盤に交互に石を落とし、先に自分の石を**縦・横・斜めのどれかに4つ並べた**ほうが勝つ2人対戦ゲームです。石は列の一番下まで落ちるので、置ける場所は「各列の一番上」だけ。三目並べより読みが深く、五目並べよりすぐ決着がつきます。

相手が見つからないときは、CPUと対戦できます。

## 1. ゲームの流れ

1. 先手は**シアン**、後手は**マゼンタ**の石を使います。
2. 自分の番になったら、石を落としたい**列**をタップします（盤の上の段でも、盤の中のどこでも構いません）。パソコンでは数字キーの **1〜7** でも落とせます。
3. 石はその列の一番下の空きマスまで落ちます。6段すべて埋まった列には落とせません。
4. 交互に繰り返し、先に4つ並べたほうの勝ちです。

## 2. 勝ち負け

- **勝ち**：自分の石が、縦・横・斜めのどれかに4つ以上つながったとき。並んだ石が黄色く光ります。
- **引き分け**：42マスすべてが埋まっても、どちらも4つ並ばなかったとき。

## 3. 持ち時間

- 1手の持ち時間は **15秒** です。画面上のバーが残り時間で、残り5秒になると赤くなります。
- 時間切れになると、**空いている列のどこかにランダムで自動的に落とされます**。負けにはなりませんが、思わぬ場所に落ちて不利になることがあります。

## 4. 先手と後手

- 1試合目は、部屋に先に入った人が先手です。
- 同じ相手と続けて遊ぶ（再戦する）と、**1試合ごとに先手と後手が入れ替わります**。四目並べは先手がやや有利なので、交互に入れ替えて公平にしています。

## 5. 楽しみ方のコツ

- **真ん中を取る**：真ん中の列（4列目）は、横にも斜めにも4つ並べる組み合わせが一番多い列です。序盤は真ん中とその両隣を取ると有利です。
- **ダブルリーチを作る**：「ここに落とせば4つ並ぶ」マス（リーチ）を2つ同時に作れば、相手は片方しか防げません。
- **相手のリーチの真下に注意**：相手が「そこに置けば勝ち」のマスが宙に浮いているとき、その真下に石を落とすと、相手がその上に置けるようになってしまいます。
- **CPUは強め**：CPUは数手先まで読みます。すぐ勝てる手・すぐ負ける手を見逃しません。

## 6. 観戦と配信

- 対戦の途中から入った観戦者にも、数秒以内に今の盤面が表示されます。
- OBS透過モードに対応しています。背景が透けても、盤面と石はそのまま表示されます。
- 右上のスピーカーのボタンで、音をオン・オフできます。
