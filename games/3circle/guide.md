# 【遊び方】3Circle：並べるか、重ねるか。大・中・小のリングで揃える陣取りゲーム

「**3Circle**」は、大・中・小の3サイズのリングを3×3の盤に置いていき、決められた形を自分の色だけで先に揃えた人が勝つ、2〜4人用のボードゲームです。人数が足りないときはCPUが入ります。

## 1. 盤と持ち駒

- 盤は **3×3の9マス** です。各マスには **大・中・小のスロットが1つずつ** あり、1マスに3サイズすべてを重ねて置けます。
- 持ち駒は、**大・中・小が3個ずつ** です。
- 色は赤・青・黄・緑の4色です。**2人で遊ぶときは、1人が2色を受け持ちます**（赤と黄、青と緑）。3人なら3色、4人なら4色を使います。

## 2. 基本ルール

1. 最初の手番はランダムで決まり、そこから色の順番（赤→青→黄→緑）に回ります。
2. 自分の番では、持ち駒から **好きなサイズを1つ** 選び、盤上の **空いている同じサイズのスロット** に置きます。
3. 置ける場所がない色は飛ばされ、次の色の番になります。

## 3. 勝利条件

次のどれかを **自分の色だけで** 最初に完成させた人の勝ちです。

1. **同サイズ一列**：縦・横・斜めのどれかに、同じサイズを3つ並べる
2. **昇順・降順一列**：縦・横・斜めのどれかに、大・中・小（または小・中・大）を順に並べる
3. **同心円**：1つのマスに、大・中・小を重ねて揃える

誰も置ける場所がなくなった場合は **引き分け** です。

## 4. 攻略のコツ

- **勝ち筋は3種類**：「並べる」だけでなく「重ねる」でも勝てます。相手の色が1つのマスに2つ重なっていたら、残りのサイズのスロットを埋めて止めましょう。
- **中央のマスは要所**：中央のマスは縦・横・斜めの4本の列に関わるうえ、重ねる勝ち方にも使えます。
- **持ち駒の残りを見る**：各サイズ3個しかないので、相手が使い切ったサイズでは、その相手は並べられません。
- **2人対戦は2色の連携**：自分の2色は別々に数えられるので、どちらか1色で揃える必要があります。2色で相手の邪魔を分担しましょう。
