# ネオン・ケーキカットの遊び方・ルール｜ケーキを等分する対戦ゲーム

## ネオン・ケーキカットとは

画面に出たケーキを、指示された数にできるだけ同じ大きさで切り分ける対戦ゲームです。ケーキの形は丸・三角・四角・五角形・六角形のどれかで、何等分にするかは2〜6のどれかです。どちらも試合ごとにランダムに決まり、参加者全員に同じお題が出ます。

全員が同時に切り、答え合わせで1切れずつの大きさがパーセントで表示されます。2〜4人で遊べて、1試合は1分ほどで終わります。

## 遊び方

### 始まり方

試合が始まると、お題（例：「五角形のケーキを 3 等分！」）が表示され、3秒のカウントダウンのあとに切り始めます。

### 切り方

- ケーキの上を指でなぞる（パソコンはマウスでドラッグする）と、なぞった線で切れます。まっすぐな線でも曲がった線でもかまいません。
- 線は指示された数（3等分なら3本）まで引けます。
- ケーキを切り分けるには、線をケーキの縁から縁まで、または別の線までつなげます。縁や別の線の少し手前で止まった線は、そこまで伸ばしてつなげます。
- 画面の下に、今の線の本数と、今いくつに切れているかが表示されます。
- 「1本戻す」で直前の線を、「クリア」で全部の線を消せます。
- 切り終えたら OK を押します。OK を押したあとは切り直せません。

ほかの人の切り口は、答え合わせまで見えません。誰が OK を押したかだけが表示されます。

### 時間

切れるのは20秒です。時間切れになると、その時点の切り口で自動的に OK になります。

### 答え合わせと勝敗

全員が OK を押すか時間切れになると、答え合わせが始まります。部屋の順番で1人ずつ、切り分けた1切れずつの大きさと称号を見せていきます。順位は、全員の答え合わせが終わってから表示します。

順位は次の順で決まります。

1. 指示された数に切れた人が上位です。
2. その中では、理想の大きさからいちばんずれた1切れのずれが小さい人が上位です（ずれは0.1%単位で比べます）。
3. ずれが同じなら、先に OK を押した人が上位です。

指示された数に切れなかった人は、指示との差が小さい人ほど上位で、差が同じなら先に OK を押した人が上位です。ケーキの1%に満たない小さな切れ端は、1切れに数えません。引き分けはありません。

### 称号

指示された数に切れた人には、理想の大きさに対するずれの割合で称号が付きます。

| 称号 | ずれ（理想の大きさに対して） |
|---|---|
| 神の包丁 | 4%以内 |
| パティシエ | 10%以内 |
| ケーキ職人 | 20%以内 |
| 見習い | 35%以内 |
| ケンカのもと | 35%より大きい |

指示された数に切れなかった人は「切り足りない」か「切りすぎ」、線を1本も引かなかった人は「手つかず」になります。

## 上手に切るコツ

- **中心を通る線を使います。** 丸・四角・六角形は、中心を通るまっすぐな線で2つに切ると同じ大きさになります。4等分や6等分は、中心で交わる線を組み合わせると揃えやすくなります。
- **中心から外へ切る方法もあります。** 3等分や5等分は、中心から縁へ向けて線を放射状に引くと、ケーキらしい切り方で分けられます。中心をはさんだ角度を揃えるのがコツです。
- **三角と五角形は向きに注意します。** 中心を通る線でも、角の位置によって2つの大きさが変わります。角と辺の位置を見て線を引きます。
- **数を先に確かめます。** 画面の下の「いま ◯ 切れ」が指示の数になっているかを見てから OK を押します。数が違うと、どれだけきれいに切っても上位になれません。
- **急ぎすぎません。** 先に OK を押した方が勝つのは、ずれが同じときだけです。20秒あるので、線を引き直してから押しても間に合います。
